Start the connector on the machine

The machine needs Docker with the NVIDIA Container Toolkit, and should be used only for testing. On it, in a new folder:

curl -fsSLO https://raw.githubusercontent.com/eidonix-ai/autobot/main/deploy/connector/compose.yml
curl -fsSL -o .env https://raw.githubusercontent.com/eidonix-ai/autobot/main/deploy/connector/example.env
chmod 600 .env           # then edit .env: see below
docker compose pull && docker compose up -d
docker compose run --rm connector check

In .env, set at least:

AUTOBOT_URL={{.URL}}
CONNECTOR_TOKEN=the token above
WORK_IMAGE=the image runs use, such as flare-donor-work:local
MODELS_DIR=a folder of models, such as /home/you/.cache/huggingface/hub

The check must end with "The job container is isolated as required." The machine then shows as Ready on the workspace page.
