Case files for contributors' agents

Autobot's comments can link to a case file, which a contributor's agent may read for more detail at /api/v1/cases/<uuid>. Each case's address is random and unguessable. For a public repository, the address is enough.

For a private repository, the agent must also send a secret that only people with access to the repository can read: the contents of {{.SecretPath}} on the default branch, as a bearer token. To set it up, commit a file there containing, for example:

{{.NewSecret}}

Autobot reads the file with this workspace's GitHub identity and never writes to the repository. To rotate the secret, commit a new value; the old one stops working within five minutes. Rotate it when someone loses access to the repository.
